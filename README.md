# HidroSense · Riego

App web para ver y controlar el nodo de riego HidroSense (ESP32) desde cualquier lugar.

- Sin contraseña no muestra nada: los datos llegan cifrados (AES-256-GCM, clave PBKDF2) por MQTT.
- Este repositorio solo contiene la página; ni el código del equipo ni la contraseña se guardan aquí.
